This directory holds the detailed material behind the submission README. The

running, and evaluating the system.

## Documentation boundary

The design and development records are historical supporting material; they do
not replace the source code or runtime tests as the authoritative description
of current behavior.

## Current prototype scope

The delivered system combines public NTU/CCDS academic information with
simulated student and operational records. It provides a grounded exception
workflow, visible human checkpoints, a transparent execution interface, a
read-only data explorer, and isolated evaluation evidence. It is a research
prototype, not an official NTU service.
