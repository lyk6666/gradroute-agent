# Pre-development design

These documents define the original problem framing and design decisions. They
are retained as context for the implemented system, whose current behavior is
defined by the source code and tests.

- [01 — Data design](01_data_design.md): public grounding, simulated data, and
  provenance boundaries.
- [02 — Solution architecture](02_solution_architecture.md): workflow topology,
  memory semantics, tools, safety edges, and approval boundaries.
- [03 — Demo scenarios](03_demo_scenarios.md): the scenario families and their
  intended resolution paths.
- [04 — Simulation design](04_simulation_design.md): population, timeline,
  transaction, and approval simulation approach.
- [05 — Evaluation plan](05_evaluation_plan.md): final-state, control-flow,
  memory, and robustness criteria.
